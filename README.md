# Caça-Palavras

Jogo educativo desenvolvido com HTML, CSS e JavaScript.

## Como executar
1. Baixe ou copie os arquivos do projeto.
2. Abra o arquivo `index.html` em um navegador moderno.
3. Escolha uma palavra na grade tocando na primeira
   letra e depois na última.
4. Encontre todas as palavras para vencer.

## Tecnologias
HTML5, CSS3 e JavaScript puro.

## Objetivo acadêmico
Praticar desenvolvimento web, lógica de programação,
manipulação do DOM e criação de interfaces responsivas.
