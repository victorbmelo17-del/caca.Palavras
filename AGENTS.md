# Instruções do projeto

Os PRDs devem ser sempre criados na raiz do projeto atual,
seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.

## Boas práticas
- Manter o código simples e organizado.
- Garantir compatibilidade com dispositivos móveis.
- Priorizar acessibilidade e legibilidade.
- Testar as funcionalidades antes da entrega.
